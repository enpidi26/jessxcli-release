# jessxcli-release

Official releases and one-liner installers for **[jessx](https://github.com/enpidi26/jessxcli)**.

---

## ⚡ Quick Install

### Windows (PowerShell)
```powershell
irm https://raw.githubusercontent.com/enpidi26/jessxcli-release/main/install.ps1 | iex
```

### macOS / Linux (Terminal)
```bash
curl -fsSL https://raw.githubusercontent.com/enpidi26/jessxcli-release/main/install.sh | sh
```
